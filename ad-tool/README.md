# Ad tool

The office's ad-making tool: one static page (`frontend/public/index.html`) with the agents' photos and the logo (`frontend/public/images/`). No sign-in, no server of its own.

- **Address:** its own Railway service, and also `/ad-tool` on the CRM's address (the CRM forwards it). Keep the second one: the CRM's **יצירת מודעה** button opens `/ad-tool#...` with the property already filled in (the details travel after the `#`, so they never reach a server), and the agent photos are stored in the database as `/ad-tool/images/...`.
- **Agents:** the page reads the office team list straight from the database through the public function `ad_tool_agents()` (publishable key, in the page). It returns only what every ad already prints: name, role, license, phone and photo. Adding, editing and removing agents is done only by the admin, on the **ניהול סוכנים** page in the CRM; a change there shows in the ad tool too.
- **Title on the ad:** each team-list row has a `gender` (chosen at sign-up, fixable by the admin), a `license` and a `photo_url`. סוכן / סוכנת נדל"ן follows from the gender; until an agent has one, the old stored `role` is used. Photos are cut-out portraits (transparent, 800×800).
- **Run locally:** `cd ad-tool/frontend && npm install && npm start` (http://localhost:3002/ad-tool). `serve.json` makes `/ad-tool` and `/ad-tool/images/...` work the same way here as behind the CRM.
- **Designs:** the same ad comes in three looks: the original one (קלאסי, locked, see the design notes), גל and שמיים. The agent picks one in the last card of the form; everything already filled in stays, and the browser remembers the choice. In `index.html` each design is a unit of its own: its HTML in a `<template id="tpl-...">`, its rules in `<style id="ad-designs">` under its own prefix, and one row in the `DESIGNS` table of the script. All designs use the same element ids, so the same functions fill them.
- **Design artwork:** the curves, ribbons, price seal, clouds and balloon are image files, `frontend/public/images/design-*.webp`, drawn from [design-src/art.html](design-src/art.html) by `design-src/render_art.py`. The small pictures in the form come from `design-src/render_thumbs.py`, which fills the running tool with made-up details and drawn photos (`sample-photos.html`), so no real property is kept in the repository. Both scripts need `pip install playwright pillow`.
- **The saved picture must match the preview.** The classic design is drawn by `renderClassic` (photos painted by hand around one html2canvas pass); the other designs by `renderFlat` (photos cut to their frames first, then one pass). In a new design: no SVG, `clip-path`, `mask` or `filter`; a rounded element with a `box-shadow` keeps its fill on an inner `-bg` layer; fonts only from static files (`HeeboAd`). Check a change in Chrome and in Safari, comparing the downloaded file with the preview.
- Design notes: [design-notes.md](design-notes.md).

- **Deploys:** its own Railway service (root directory `/ad-tool/frontend`), rebuilt on every push to `main` that touches this folder.
